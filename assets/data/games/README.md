# ゲームメタデータディレクトリ

このディレクトリには各ゲームのメタデータファイルが個別に格納されています。

## 構造

- `index.json`: すべてのゲームファイルのリスト
- `<slug>.json`: 各ゲームのメタデータ（個別ファイル）

## 新しいゲームを追加する方法

1. `games/<slug>/` ディレクトリにゲームファイルを作成
2. このディレクトリに `<slug>.json` ファイルを作成：

```json
{
  "slug": "your-game-slug",
  "title": "ゲームのタイトル",
  "description": "ゲームの説明",
  "tags": ["タグ1", "タグ2"]
}
```

3. `index.json` にファイル名を追加：

```json
[
  "existing-game.json",
  "your-game-slug.json"
]
```

## マージコンフリクトの回避

この構造により、複数のブランチで同時にゲームを追加してもコンフリクトが最小限に抑えられます：

- 各ゲームは独立したJSONファイルなので、異なるゲームを追加する場合はコンフリクトが発生しません
- `index.json` は単純なリスト構造のため、コンフリクトが発生しても解決が容易です
